# Exploratory Data Analysis and Machine Learning

## 📌 Project Overview

This project performs comprehensive Exploratory Data Analysis (EDA) and applies statistical analysis and machine learning techniques to the **Kostecki-Dillon dataset**. It explores relationships between variables, identifies patterns, performs clustering, reduces dimensionality using PCA, and builds regression and classification models.

## 🎯 Objectives

- Perform data cleaning and preprocessing.
- Conduct univariate, bivariate, and multivariate analysis.
- Visualize distributions and relationships between variables.
- Apply K-Means and Hierarchical Clustering.
- Perform Principal Component Analysis (PCA).
- Implement Simple Linear Regression (SLR).
- Apply Logistic Regression and Decision Tree classification.
- Evaluate and compare model performance.

## 📊 Dataset Description

The project uses the Kostecki-Dillon dataset, containing variables related to observations such as age, air quality (`airq`), time, dosage (`dos`), headache, medication, and sex.

The dataset is explored to understand distributions, relationships, and potential patterns among its variables.

## 🔍 Project Workflow

### 1. Data Preprocessing
- Dataset loading and inspection
- Missing-value analysis
- Duplicate-record checks
- Data-type inspection
- Categorical-variable analysis

### 2. Univariate Analysis
- Mean, median, and mode
- Variance and standard deviation
- Range, skewness, and kurtosis
- Histograms, box plots, and frequency distributions

### 3. Bivariate Analysis
- Covariance and correlation
- Scatter plots and pair plots
- Categorical versus numerical analysis
- Categorical versus categorical analysis
- Chi-square tests

### 4. Multivariate Analysis
- Three-dimensional scatter plots using Age, AirQ, and Time
- Exploration of relationships among multiple variables

### 5. K-Means Clustering
- Standardization of numerical features
- Elbow Method
- Silhouette Score
- Identification of clusters

### 6. Hierarchical Clustering
- Single Linkage
- Complete Linkage
- Ward Linkage
- Dendrogram visualization
- Comparison with K-Means using the Silhouette Score

### 7. Principal Component Analysis (PCA)
- Standardization of numerical features
- Dimensionality reduction
- Explained variance analysis
- Cumulative explained variance visualization
- Visualization of the first two principal components

### 8. Simple Linear Regression (SLR)
- Predicting AirQ using Age as the independent variable
- Training and testing data split
- Model fitting and prediction
- Evaluation using:
  - Mean Absolute Error (MAE)
  - Mean Squared Error (MSE)
  - R-squared score

### 9. Classification
Two classification algorithms are implemented to predict headache outcomes:

**Logistic Regression**
- Numerical and categorical feature preprocessing
- Model training and prediction
- Accuracy, precision, recall, and F1-score
- Confusion matrix

**Decision Tree Classifier**
- Tree-based classification
- Model evaluation using classification metrics
- Confusion matrix

The classification models are compared using test-set accuracy.
